# Semantics@Suren

A structured learning journey exploring semantic retrieval, representation learning, and modern retrieval architectures.

This repository shares the **lessons learned, conceptual insights, and learning documentation** developed through the journey.

### About the Lab

The underlying experimental lab—including code, datasets, and working artifacts—is maintained separately and is not publicly shared. This repository is intended to make the learning outcomes and documented insights accessible.

### Purpose

To share knowledge, document the learning journey, and contribute to the broader understanding of semantic retrieval systems.
